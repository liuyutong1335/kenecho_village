## 1. プロジェクト概要

### 背景・目的
健康記録が長続きせず、会話での返答に迷う会社員向けに、**記録を続けるきっかけ**と**短い会話を練習する場**を提供する。

食事・運動・睡眠・体重の健康記録がペットを成長させ、ペットと一緒に架空の NPC との会話クエストへ参加する。ユーザーは 3 つの返答から 1 つを選び、NPC の反応とペット固有のアドバイスを確認しながら、会話を続ける方法を体験する。

### 中心ループ
```
健康記録 → 健康EXP獲得 → ペット成長 → ペットと外出 → NPCとの会話クエスト
→ 3択回答 → NPCの反応 → ペットのアドバイス → きずな度上昇
→ 特別会話・思い出 → ペットの旅立ち → 新しい卵 → 次世代
```

### 対象ユーザー（架空ペルソナ）
高橋 翔太（23歳・入社1年目の会社員・架空）。開発・テスト・デモでは実在人物・企業・顧客・実際の健康記録を使用しない。

## 2. 対象範囲 / スコープ外

- **対象**：初期設定／健康記録（食事・運動・睡眠・体重）／健康目標・BMI・基礎代謝／日次健康評価と健康EXP／ペット育成（卵→幼体→成長期→成体→陪伴期→旅立ち→次世代）／孵化と種類公開（選択・おまかせ）／会話クエスト（1日1回）・会話練習モード／きずな度と関係段階／交流ノート・図鑑・思い出／保存・復元・初期化／研修デモツール
- **対象外**：複数プロフィール／サーバ同期・ログイン／医療・栄養・心理診断／実在データ連携／スマホ向け最適化

## 6. はじめての使い方

1. `kenecho-village.html` を開くと初期設定が始まります（表示名 → 年齢・性別 → 身長・体重 → ペット名 → 決定方式）
2. ホームで食品・運動・睡眠・体重を記録します（過去日付の記録も可）
3. 1日の記録を「評価確定」すると健康EXPを得てペットが育ちます
4. ペット小屋から「外へ出る」と卵が孵化し、種類が公開されます
5. 会話クエストで NPC との3択会話を1日1回プレイできます（練習モードは無制限）
6. 交流ノート・図鑑・思い出で関係とペットの歴史を確認できます
7. 会話クエスト画面の「小さな約束」入口から、朝・昼・夕方に1日1章の短編物語を進められます（全4章・結末2種）。設定>研修デモツールからは独立データで4章を連続体験できます

※ 詳細は `docs/01_要件定義書.md`〜`docs/04_テスト仕様書.md` を参照。
