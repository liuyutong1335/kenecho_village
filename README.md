## 1. プロジェクト概要

### 背景・目的
健康記録が長続きせず、会話での返答に迷う会社員向けに、**記録を続けるきっかけ**と**短い会話を練習する場**を提供する。

食事・運動・睡眠・体重の健康記録がペットを成長させ、ペットと一緒に架空の NPC との会話クエストへ参加する。ユーザーは 3 つの返答から 1 つを選び、NPC の反応とペット固有のアドバイスを確認しながら、会話を続ける方法を体験する。

### 中心ループ
```
健康記録 → 健康EXP獲得 → ペット成長 → ペットと外出 → NPCとの会話クエスト
→ 3択回答 → NPCの反応 → ペットのアドバイス → きずな度上昇
→ 特別会話・思い出 → ペットの旅立ち → 新しい卵 → 次世代
```

### 対象ユーザー（架空ペルソナ）
高橋 翔太（23歳・入社1年目の会社員・架空）。開発・テスト・デモでは実在人物・企業・顧客・実際の健康記録を使用しない。

## 2. 対象範囲 / スコープ外

- **対象**：初期設定／健康記録（食事・運動・睡眠・体重）／健康目標・BMI・基礎代謝／日次健康評価と健康EXP／ペット育成（卵→幼体→成長期→成体→陪伴期→旅立ち→次世代）／孵化と種類公開（選択・おまかせ）／会話クエスト（1日1回）・会話練習モード／きずな度と関係段階／交流ノート・図鑑・思い出／保存・復元・初期化／研修デモツール
- **対象外**：複数プロフィール／サーバ同期・ログイン／医療・栄養・心理診断／実在データ連携／スマホ向け最適化

| 領域 | 機能 |
| --- | --- |

| 過去日付 | 記録の追加・編集・削除（確定済み EXP・きずな度は再計算しない・未来日付不可） |

| 評価 | 日次スコア（食事/運動/睡眠 各0〜2）→ 健康EXP（1日上限100・二重付与禁止） |
| ペット | 6種（うさぎ・きつね・こぐま・ねこ・ことり・たぬき）×コーチタイプ／卵→旅立ちの6段階／健康状態表示 |
| 孵化 | 初回外出で孵化→種類決定（選択・おまかせ・次世代は直近種除外）→図鑑登録（同一処理で原子的保存） |
| 会話 | 架空シーン20件（日常8/仕事6/食事交流6）・架空NPC 8名／3択回答＋NPC反応＋解説＋ペット助言／今日のクエスト（1日1回）／練習モード（4ターン＋条件ボーナス・きずな度不変） |
| きずな度 | NPC別（+8/+3/−4・1日1回）／ペット世代別（+2・1日1回）／総合（ペット×0.4＋NPC×0.6）／5段階 |
| 記録・収集 | 交流ノート／ペット図鑑／思い出（世代別）／旅立ち→次世代 |
| 運用 | 保存・復元・破損隔離・データ初期化（確認付き）／研修デモツール（世代循環確認） |

## 5. 導入・起動方法

Git・Node.js は開発者のみ必要です（実行には不要）。

```bash
# 1. リポジトリを取得（または ZIP 展開）
git clone <repository-url>

# 2. インストール不要。そのまま起動
#    「index.html」を Chrome または Edge で開く（ダブルクリック可）
```

- サーバ起動・ビルド・通信は一切不要
- ロジックの自動テストは `node --test tools/tests/` で実行（Node.js 18以降）

## 6. はじめての使い方

1. `index.html` を開くと初期設定が始まります（表示名 → 年齢・性別 → 身長・体重 → ペット名 → 決定方式）
2. ホームで食品・運動・睡眠・体重を記録します（過去日付の記録も可）
3. 1日の記録を「評価確定」すると健康EXPを得てペットが育ちます
4. ペット小屋から「外へ出る」と卵が孵化し、種類が公開されます
5. 会話クエストで NPC との3択会話を1日1回プレイできます（練習モードは無制限）
6. 交流ノート・図鑑・思い出で関係とペットの歴史を確認できます

※ 詳細は `docs/01_要件定義書.md`〜`docs/04_テスト仕様書.md` を参照。

## 10. 主な数値仕様

| 項目 | 値 |
| --- | --- |
| 健康スコア | 食事/運動/睡眠 各0〜2点、合計0〜6点 |
| 健康EXP | 未記録:0、0点:15、1:25、2:40、3:55、4:70、5:85、6:100（1日上限100・確定時のみ） |
| 成長段階 | 卵→幼体→成長期→成体→陪伴期→旅立ち（閾値・最低日数は `js/config.js`） |
| NPCきずな度 | 初期40／+8・+3・−4／0〜100補正／NPCごと1日1回 |
| ペットきずな度 | 初期20／クエスト完了+2／1日1回／世代別 |
| 総合きずな度 | `round(ペット×0.4 ＋ NPC×0.6)` |
| 基礎代謝 | Mifflin–St Jeor（成人・kcal/日・参考情報） |
| 目標初期値 | 摂取カロリー上限2000kcal／蛋白質 体重×1.0g／運動30分／睡眠7時間 |

## 11. 制約・セキュリティ・注意事項

- **研修・学習用途**。数値・助言は診断ではなく健康管理・会話練習の参考情報です
- **外部通信なし**・ログインなし・アカウント情報を収集しません
- データはブラウザの localStorage のみに保存されます。**共有PCでは他ユーザーに閲覧される可能性**があります。個人・勤務・顧客情報は保存しないでください
- ブラウザの履歴消去・サイトデータ削除でデータは失われます（定期的なバックアップ手段はありません）
- リスクを「ゼロ」と表現しません。利用は自己責任でお願いします
- キャラクター・食品・運動・会話シーンはすべて架空のオリジナルです
