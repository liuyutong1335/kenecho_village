# kenecho Village UIデザイン仕様書

バージョン：1.0　／　状態：確定（実装開始時点）

---

## 1. デザインコンセプト

オリジナルの「温かい田園生活風ピクセル UI」。特定の既存作品名を文書・画面へ記載せず、既存ゲームのキャラクター・マップ・画像・フォント・配色・モーションを模倣しない。
木・草・土・紙・布の素材感を基本とし、どの画面でも同じトーンを保つ。

## 2. 基本ルール

- 8px グリッドを基準にレイアウト。小装飾は 4px 単位
- 枠線は 2px または 4px（太め・角は直角）
- 右下へずらした硬い影（ぼかしなし・オフセット固定）
- 大きな角丸・ぼかし・ガラス表現・グラデーション多用を避ける
- ピクセル素材は整数倍率（3〜4倍）で拡大し、補間がない最近傍近似で描画
- 主要キャラクターに絵文字を使用しない（UIアイコン・背景装飾は可）
- 外部画像・外部フォントを使用しない（システムフォント＋字下げ・太字で質感を出す）

## 3. 基本色（CSS カスタムプロパティに定義）

```css
--sky: #A9D6D2;      /* 空色 */
--grass: #7FA650;    /* 草色 */
--grass-dark: #56733E; /* 濃い草色 */
--wood: #9A6642;     /* 木材 */
--wood-dark: #5B3A29; /* 濃い木材 */
--soil: #C9965B;     /* 土 */
--paper: #F4DDAA;    /* 紙 */
--paper-shadow: #D1A85B; /* 紙の影 */
--sun: #E9B949;      /* 黄色 */
--green-safe: #6FAF65; /* 安心の緑 */
--orange-warn: #D9824B; /* 注意の橙 */
--red-dark: #A94E45;  /* 暗い赤 */
--ink: #3E2F28;      /* 本文 */
--ink-sub: #66564D;  /* 補足 */
```

- 状態色：成功＋=`--green-safe` ／ 注意=`--orange-warn` ／ 警告・削除=`--red-dark`
- 色だけで状態を表さない（アイコン・文字・罫線パターンを併用）

## 4. グリッドとタイポグラフィ

- 基準グリッド：8px。コンテンツ幅はラッパー最大 920px 程度、中央寄せ
- 本文：16px 以上（`font-size`）。見出しは 18〜28px
- 行間：1.6 前後。パネルの内余白は 16px（8px×2）
- フォント：`system-ui, "Hiragino Sans", "Meiryo", sans-serif`。モノ幅記号は `ui-monospace`
- 詰め物を避ける：読みやすさ優先で適度なホワイトスペースを保持

## 5. 共通部品

### 5.1 トップバー（木製看板風）
- 左：ロゴ「kenecho Village」（クリックでホームへ）
- 中央〜右：記録／ペット／会話クエスト／交流ノート／思い出／図鑑／設定
- 常時表示：右上に「研修用・本番利用不可」の札（紙色・注意の橙で塗分け）
- モバイル非対応のため固定横幅での横並びでも可（920px内に収まらない場合は折り返し）

### 5.2 パネル／窓（木枠＋紙背景）
- 外枠：`--wood-dark` 4px、内側 `--wood` 2px
- 中身：`--paper` 背景、右下 4px の硬い影（`--paper-shadow`／`--wood-dark`）
- 見出し札：紙色の横長タグに `--ink` の文字
- ボタン：高さ 48px 以上。紙色（通常）／木色（主要）／注意色（削除・危険）
  - 押下時は影を消して 2px 下へ（擬似 3D の立体感）
  - `hover`／`focus-visible`（2px 黄色のアウトライン）を必ず表示

### 5.3 フォーム
- ラベルは明示し、単位を併記（例「身長 cm」）
- 入力欄：紙地に `--ink` 文字、枠 `--wood-dark` 2px、フォーカスで黄色枠
- エラー：入力欄直下へ 16px の文章（`--red-dark`）。`aria-describedby` で関連付け
- セレクト・チェックボックスも同トーンで統一

### 5.4 モーダル
- オーバーレイを暗転（`rgba(0,0,0,.45)`）+ 中央に木枠パネル。`role="dialog"`・`aria-modal="true"`
- 確認モーダル：内容・「キャンセル」/「実行」ボタン。危険操作は「実行」を注意色に
- 通知：紙札スタイルのトーストを画面下部へ表示（自動消滅・閉じるボタン付き）

### 5.5 掲示板・手帳等
- 木製掲示板：ペット小屋の「今日の記録状況」。記録済み項目にスタンプ風マーク
- 手帳：記録画面の背景。行罫・メモ枠を紙上に表現
- 図鑑／思い出：紙・布の素材感カード

## 7. 会話画面の演出

- 背景＋人物は1枚に合成したピクセル風景（職場／エレベーター／休憩室／飲食／屋外）。「あなた・ペット・NPC」が背景の地面線上に立ち、呼吸（上下）・発言（talkで口）・回答後の表情変化で動く、人物が背景に溶け込んだ動画として表示する
- 発言者名は木札で表示。発言は紙の会話ボックス
- 会話結果は `aria-live="polite"` の領域へ「NPCの反応」「解説」「ペットの助言」の順に文章で提示
- ペットの助言は「今回のポイント」と「改善例」の2行で提示（改善例は小さめの補足表示）
- 練習画面のターンヘッダーに「導入／展開／応答／締め」の役割ラベルを表示（クエストは「導入・1ターン」の注記）
- 文字送り演出は省略可とし、クリックで全文表示できる

## 8. キャラクターとスプライト

- ピクセル定義は `js/data/pixel-art/`、表示・拡大は `sprite.js`（Canvas 描画・最近傍補間）
- ペット：32×32 ベース、表示 3〜4倍（96〜128px）。6種を耳・尾・体型・配色で差別化
  - うさぎ（白×薄茶・長耳）/ きつね（橙×白・太尾）/ こぐま（茶・丸い体型）/ ねこ（グレー×クリーム・とがった耳）/ ことり（空色・小さめ）/ たぬき（茶×クリーム・縞しっぽ）
- 卵：共通デザイン（斑点で種類を推測できない抽象模様）
- NPC：chibi人型（16×12）を `js/data/pixel-art/npcs.js` で定義。髪型（short/bob/curly/bun）＋服・ズボンの配色＋店員はエプロン・知人はメガネで描き分け、表情（normal/smile/happy/shy/troubled/talk）をフレームで切替
- 未遭遇NPC・未発見ペットはシルエット（塗りつぶし黒＋輪郭）で表示
- 代替テキスト（`alt`／`aria-label`）：個体名（未公開時は「卵」・未発見は「？？？」）＋状態（「ご機嫌」等）を入れる

## 9. アニメーション

- 1動作4〜8フレーム、4〜8fps。`animation-manifest.js` でフレーム数・fps・優先順位を一元管理
- 必須動作（ペット）：`idle / blink / walk_left / walk_right / happy / troubled / sleepy / eat / exercise / talk / level_up / departure`
- 卵：`egg_idle / egg_shake / egg_hatch`
- NPC：`idle / talk / happy / neutral / troubled / appear / special`
- 優先順位（数字が小さいほど高い）：成長・旅立ち(0)＞孵化・種類公開(1)＞記録完了・会話結果(2)＞食事・運動(3)＞会話中(4)＞健康状態(5)＞通常待機(6)
- 1回動作が終われば、健康状態に対応した待機動作へ戻る
- `prefers-reduced-motion: reduce` では最初の1フレームを静止表示し、ループ停止。状態はアイコンと文字で把握可能にしておく

### 健康状態と待機動作・表情の対応

| 状態（キー） | 日本語 | 表情・動作 |
| --- | --- | --- |
| perfect | 絶好調 | ニコニコ・跳ねる idle/happy |
| happy | ご機嫌 | 微笑み・ゆれ |
| normal | ふつう | 通常の idle・blink |
| lonely | 少し寂しそう | うつむき・troubled |
| sleepy | 眠そう | 目がとろける・ゆっくり blink |

### 記録スタンプ
- 保存成功時に紙へスタンプ（丸印＋「記」）を押す演出。`--green-safe` で塗る

## 10. アクセシビリティ要件（実装規約）

- 本文 16px 以上、ボタン高さ 48px 以上
- Tab／Enter／Space で全操作可能。フォーカス順序は視覚順
- `:focus-visible` に濃い黄色アウトラインを必ず表示
- 色だけで状態を表さない（アイコン・文字・パターン併用）
- エラーは理由を文章で入力欄直下に表示
- キャラクター画像へ代替テキスト
- 会話結果は `aria-live="polite"` で通知
- 激しい点滅・高速フラッシュを使用しない
- 文字送り（タイプライター演出）はクリックで全文表示
- アニメーションなしでも状態を理解できる表示（状態ラベルを併記）
- 主要画面で文字やボタンを重ねない（重畳表現はモーダルのみ）
- 操作対象は `button`/`a`／適切な見出し階層（h1→h2…）と `main`/`nav` ランドマーク
