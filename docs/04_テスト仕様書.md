# kenecho Village テスト仕様書

バージョン：1.0　／　状態：確定（実装開始時点）

## 1. テスト方針

- 実施環境：Node.js v24（自動ロジックテスト `node --test tools/tests/`）＋ PC版 Chrome / Edge（ブラウザ確認）
- 自動テスト：計算・状態遷移・データ整合・保存復元などブラウザ非依存のロジック
- 目視テスト：UI・演出・アニメーション・コンソール/Network 確認（ユーザー実施、手順を提示）
- 記号：`[自動]` … Node テストで実施／`[手動]` … ブラウザで目視確認／`[両]` … 両方
- 各結果に「PASS/NG/保留」を付し、NG は修正後に再テスト。問題を残したまま次段階へ進まない

## 13. リグレッション

- 各マイルストーン終了時に `node --test tools/tests/` 全件 Green を維持する
- ブラウザ確認は Chrome・Edge の両方、`kenecho-village.html` 直接起動（file://）で実施
- 修正時は関連テスト群（対象モジュール＋依存モジュール）を再実行する
